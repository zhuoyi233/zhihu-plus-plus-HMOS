# ZhihuPlusPlus-HMOS v0.6.0

本次更新以**连续阅读与全应用自适应体验**为重点，带来同一问题下的连续切答、知乎日报原生阅读、设置搜索精确定位，以及统一的沉浸光感顶栏与宽屏瀑布流布局。自 v0.5.10 起，发版准备前共 17 个提交。

## 🪪 应用名称

- 应用名称改为 **“知乎Plus”**，桌面入口、应用内版本信息与分享说明同步更新。

## 📖 连续阅读与内容详情

- 支持在同一问题下连续阅读上一答和下一答，接续回答列表分页，并提前准备相邻回答。
- 上一答支持整页预览，与下一答采用对称的切换准备，改善切答闪屏、等待提示与阅读位置衔接。
- 改善回答顶栏随正文滚动的显隐、标题与作者摘要折叠，以及沉浸阅读时的系统栏显示。
- 回答详情补充热评展示，完善评论文本与头像加载占位，减少加载时整排闪色。
- 想法详情采用统一阅读排版与悬浮操作胶囊，支持正文图片及全屏查看，发布时间与可用的 IP 属地信息移至文末。

## 📰 知乎日报原生阅读

- 默认在应用内直接阅读日报正文，展示头图、图文内容、图注与栏目，并可前往知乎讨论。
- 支持从日报链接进入原生详情；解析不完整时显示提示，保留关闭原生阅读后使用旧跳转方式的选项。

## 🖥️ 宽屏与信息流

- 首页、关注、热榜与日报根据窗口宽度和系统字号自适应布局，信息流支持 1～4 列，日报宽屏采用等高网格。
- 问题回答列表、收藏夹、收藏内容、在线与本地历史、消息及个人主页支持宽屏多列瀑布流，短卡下方空间由后续内容填补。
- 宽屏长文、个人资料和私信采用居中限宽，个人主页栏目在宽屏顶栏与窄屏悬浮胶囊之间自适应切换。
- 收藏内容与历史记录复用首页卡片排版，跟随列表样式和缩略图偏好，完善头像、封面及时间信息展示。
- 改善个人主页自动分页、加载完成闪动，以及返回列表和布局变化时的阅读位置保持。

## 🎨 外观与导航

- 全应用顶栏统一沉浸光感结构、标题间距与动作入口，随滚动内容呈现渐变模糊。
- 支持新系统材质的设备使用系统光感效果，低版本保留模糊与按压反馈兜底。
- 重构“我的”页与设置页，统一页面层级和导航体验。
- 修复首页搜索胶囊阴影、关注页胶囊偏移，以及收藏和历史列表顶栏模糊失效等问题。

## 🔎 设置与登录

- 设置搜索覆盖更多具体设置项，支持别名和多词匹配，点击后自动进入对应页面、滚动定位并高亮提醒。
- 完善搜索返回、键盘收起与定位取消行为，修复高亮层遮挡设置控件点击的问题。
- 手机号登录支持选择国家和地区码。

## 🐞 构建与问题修复

- 加强发行包检查，防止热重载源码映射夹带入安装包，映射继续单独归档供问题定位。
- 修复宽屏列表分页崩溃、加载尾项渲染与私信内容限宽失效等问题。

## 📥 下载与安装

1. 下载下方附件 `ZhihuPlusPlus-HMOS-v0.6.0-unsigned.hap`
2. 使用 [小白调试助手](https://github.com/likuai2010/auto-installer) 或 [HoKit](https://github.com/yabi-zzh/HoKit/releases) 自行签名
3. 覆盖安装即可升级，原有登录状态、设置与历史数据会保留

> [!IMPORTANT]
> 要求设备系统为 **HarmonyOS 6.1.0（API 23）及以上**。
> 多栏布局随窗口宽度与系统字号调整；沉浸光感的实际效果取决于设备系统版本与材质支持。
> 本项目非知乎官方产品，内容来自知乎网站，服务端接口变化可能导致部分功能失效。
