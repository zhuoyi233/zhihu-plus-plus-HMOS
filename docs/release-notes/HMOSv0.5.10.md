# ZhihuPlusPlus-HMOS v0.5.10

本次更新以**宽屏信息流与舒适阅读体验**为重点，带来自适应两列信息流、默认舒适排版、阅读位置恢复，以及手机和平板的菜单与收藏交互改进。自 v0.5.9 起，发版准备前共 5 个提交。

## 🖥️ 宽屏信息流

- 首页、关注、热榜和日报支持自适应两列瀑布流，随横竖屏切换与窗口缩放调整布局，充分利用大屏空间。
- 宽屏首页补足首屏内容，日报日期标题保持整行显示，并改善加载动画的底栏避让。
- 各页签使用独立顶栏滚动效果，修复切换页签时模糊效果串扰，改善首屏留白与滚动渐变模糊。
- 感谢 [@wuqiangroy](https://github.com/wuqiangroy) 对宽屏两列信息流布局的贡献（[#98](https://github.com/zhuoyi233/zhihu-plus-plus-HMOS/pull/98)）。

## 📖 阅读排版与位置恢复

- 默认采用舒适排版，调整问题、回答和文章的标题层级、作者信息及正文留白，保留原有排版与自定义阅读参数。
- 正文跟随系统字号并适配宽窗口，改善公式缩放、横竖屏排版与文末操作区域的空间避让。
- 按回答和文章保存阅读位置，改善返回、重新进入和应用重启后的恢复，以及调整字号后的定位。
- 修复公式中的中文缺字与方框文字排版，长句支持换行并随窗口宽度重新排版。

## 🎨 菜单与收藏交互

- 宽窗口菜单靠近操作入口，手机使用底部面板，删除与清空等短确认改为原生居中对话框。
- 收藏面板按内容收高，在宽窗口居中显示，选择收藏夹与新建表单可在面板内切换。
- 改善手机表单的键盘避让，输入区可滚动，取消与提交按钮保持在键盘上方，并保留退出时的草稿确认。
- 恢复屏蔽规则、屏蔽记录和个人主页的更多操作入口，统一个人主页返回与更多按钮的圆形外观及按压反馈。

## 🐞 问题修复与更新说明

- 修复收藏夹内容摘要露出 HTML 标签的问题。
- 主题模式按钮根据窗口宽度与系统字号调整排列，改善大字号下的换行与宽屏空间利用。
- 私信会话顶栏使用不透明底色，避免消息正文透出后与标题叠字。
- 修复问题页关注或取消关注后，信息头关注数未同步更新的问题。
- 发行包自动内置本版本完整更新说明，并加强更新清单与安装包附件信息校验。

## 📥 下载与安装

1. 下载下方附件 `ZhihuPlusPlus-HMOS-v0.5.10-unsigned.hap`
2. 使用 [小白调试助手](https://github.com/likuai2010/auto-installer) 或 [HoKit](https://github.com/yabi-zzh/HoKit/releases) 自行签名
3. 覆盖安装即可升级，原有登录状态、设置与历史数据会保留

> [!IMPORTANT]
> 要求设备系统为 **HarmonyOS 6.1.0（API 23）及以上**。
> 本版默认使用舒适排版，可在外观设置的“正文排版”中切换“原有排版”，或调整字号、行高与段间距。
> 本项目非知乎官方产品，内容来自知乎网站，服务端接口变化可能导致部分功能失效。
