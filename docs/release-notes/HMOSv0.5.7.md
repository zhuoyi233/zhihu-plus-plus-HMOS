# ZhihuPlusPlus-HMOS v0.5.7

本次更新以**安装包大幅瘦身**为重点，同时完善公式与参考资料阅读，新增详情阅读设置和启动时剪贴板链接跳转。自 v0.5.6 起，发版准备前共 8 个提交。

## 📦 安装包大幅瘦身

- 发行包改用 Release 构建，并将源码映射移至包外归档，显著减少下载与传输所需的数据量。
- 相比 v0.5.6 的公开未签名安装包，v0.5.7 从约 **7.48 MiB 缩小至 3.00 MiB**，体积减少约 **59.9%**，下载体积降至原来的约四成。
- 包体积指未签名 HAP 文件大小，不代表安装后的磁盘占用或运行内存。

## 📖 阅读体验

- 详情页新增阅读设置入口，可在阅读过程中调整显示设置，并优化更多菜单布局，避免正文字号影响菜单列数。
- 修复文字与公式混排识别、公式尺寸异常及模糊问题，改善超宽公式与错误 SVG 的显示。
- 正文参考标记支持跳转到文末参考资料，参考条目支持打开链接并返回原阅读位置。

## 🎨 外观与导航

- 沉浸光感新增自适应、精美、轻柔、流畅四挡设置，统一调整底栏与标题栏的材质表现，并按设备能力回退。
- 修复手动沉浸光感挡位下，页面顶部返回按钮出现黑色圆形背景的问题。
- 启动时支持识别剪贴板中的知乎链接并跳转到对应内容。

## 📥 下载与安装

1. 下载下方附件 `ZhihuPlusPlus-HMOS-v0.5.7-unsigned.hap`
2. 使用 [小白调试助手](https://github.com/likuai2010/auto-installer) 或 [HoKit](https://github.com/yabi-zzh/HoKit/releases) 自行签名
3. 覆盖安装即可升级，原有登录状态、设置与历史数据会保留

> [!IMPORTANT]
> 要求设备系统为 **HarmonyOS 6.1.0（API 23）及以上**。
> 沉浸光感效果取决于设备与系统支持情况，不支持的挡位会回退为流畅效果。
> 本项目非知乎官方产品，内容来自知乎网站，服务端接口变化可能导致部分功能失效。
