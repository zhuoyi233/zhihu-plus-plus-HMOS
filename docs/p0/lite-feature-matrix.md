# Android Lite 功能迁移矩阵

> 本文件在 P0 中持续补充，以 Android Lite 为行为基线。优先级分为 MVP、Lite 对标、后置和排除。

| 领域 | Android Lite 能力 | HarmonyOS 优先级 | P0 关注点 |
| --- | --- | --- | --- |
| 账号 | 游客、Cookie、二维码、退出和刷新 | MVP | Cookie 安全、风控、会话失效 |
| 首页 | Web/移动端 Feed、分页和刷新 | MVP | 请求头、签名、分页去重 |
| 发现 | 关注、热榜、日报和搜索 | MVP | DTO 和分页契约 |
| 内容 | 问题、回答、文章和想法 | MVP | 长正文、图片、公式和链接 |
| 用户 | 用户主页、关注状态和内容列表 | MVP | URL 解析和分页状态 |
| 评论 | 评论、回复和评论导航 | Lite 对标 | 弹层、滚动和返回栈恢复 |
| 互动 | 赞同、反对、感谢、关注和收藏 | Lite 对标 | 写请求、乐观状态与回滚 |
| 历史 | 在线历史、本地已读和打开记录 | Lite 对标 | RDB schema 和去重 |
| 通知 | 应用内通知列表和偏好 | Lite 对标 | 分类接口和默认 opt-in 语义 |
| 过滤 | 关键词、用户、话题、广告和付费过滤 | MVP | 规则一致性和记录表 |
| 本地推荐 | 爬取、行为记录和规则评分 | Lite 对标 | 非 AI 边界、TaskPool、后台限制 |
| 创作 | 写回答、写想法、图片上传和草稿 | Lite 对标 | 上传风控和草稿安全 |
| 媒体 | 图片预览、视频、扫码、分享和 TTS | 后置 | API 24 Kit 能力与权限边界 |
| 导出 | Markdown、HTML、长图和 PDF | 后置 | 像素有效性、存储 Picker |
| 更新 | Android APK 自更新 | 排除 | 改为应用市场更新策略 |
| 端侧 AI | HanLP、Embedding 和语义匹配 | 排除 | 禁止依赖、代码和模型进入项目 |
| AI 总结 | 远端知答总结 | 排除于基线 | 需用户重新确认才可立项 |

## P0 结束前需要补齐

- 每项能力对应的 Android 页面、ViewModel、Repository 和测试路径。
- 必须迁移的 preference key、默认值和数据类型。
- API 端点、请求头配置、Cookie 要求和是否需要 ZSE。
- Android workaround 的触发条件和上游链接。
- HarmonyOS 目标模块、API 24 验收用例和系统能力要求。
