# P0 技术验证任务表

## 目标

在全面迁移页面之前，验证 HarmonyOS 版本矩阵、知乎接口兼容性、会话安全、正文原生渲染和本地存储，消除会导致整体方案返工的高风险项。

## 执行顺序

1. 工具链、Bundle Name、签名和设备。
2. HTTP、Cookie、ZSE 和登录。
3. 正文 AST、公式和图片。
4. Preferences、RDB、深链、扫码和后台任务。
5. 汇总通过项、阻塞项、性能基线和架构调整。

## P0 退出条件

- P0-ENV-01、P0-NET-01、P0-SES-01、P0-ZSE-01、P0-READ-01、P0-MATH-01、P0-DB-01 全部通过。
- 签名和设备若仍受外部条件阻塞，必须给出责任人、解除条件和复测命令，不能标记为通过。
- 所有 API 24 专属能力都有 API 20 的版本判断和降级策略。
- 没有引入端侧 AI 依赖、模型文件或推理代码。
