# P4-7 系统分享验证记录

> 切片：P4-7 系统分享收口（第一完整切片）
> 分支：`feature/p4-sharing`
> 日期：2026-08-20

## 交付范围

- 统一 `SharePayload` / `ShareService` 合同，覆盖文本链接、可信图片 URL、应用临时图片与应用生成文件；
- 文本只接受受信知乎回答、文章、问题、想法、用户主页和视频链接；标题、摘要均有长度、HTML 和敏感头字段门禁；
- 图片 URL 只接受精确 `*.zhimg.com` 图床，作为 `text/plain` 的安全降级；二进制图片和文件仅接受 `cacheDir/p4-share/` 中的单层受控文件名；
- MIME allowlist：JPEG、PNG、WebP、GIF、`text/plain` 与 PDF；分享 Want 只携带受控 URI、MIME、标题/摘要和临时只读 URI 授权；
- 临时文件策略：创建后最长 24 小时，分享面板成功拉起后延迟 30 分钟清理；清理器由后续图片/导出文件生产者统一调度，不能影响草稿或相册原件；
- 正文图片“分享 URL”已接入统一服务，保留可信 URL 降级。尚未生成的二进制图片、文件不伪造平台调用。

## 自动化验证

`ShareService.test.ets` 覆盖：

- 三类 payload、知乎内容 URL 和图床 URL allowlist；
- HTML、Cookie/Authorization 文本、相似域名、双来源图片、超范围 cache 路径、路径穿越、过期临时文件和 MIME 拒绝；
- 临时文件 grace period / hard expiry；
- Want 不含 Cookie、Authorization 或自定义 header，文件仅使用 `ability.params.stream` 和读授权；
- fake launcher 的取消、无处理方错误映射和固定用户文案。

## API 24 设备验收清单（待人工执行）

- [ ] 回答、文章、问题、想法、用户主页分别打开文本分享，至少选择两个系统目标；
- [ ] 正文可信图片 URL 打开分享面板，取消不显示错误；
- [ ] P4-2 生成临时图片后验证二进制图片分享、接收方读权限与 30 分钟回收；
- [ ] P5 或导出功能生成 PDF/文本后验证文件分享、无处理方和权限拒绝提示；
- [ ] 清理任务不能删除草稿图片、相册图片或 `p4-share` 目录之外的任意文件。

## 已知限制

- 本切片不下载远程图片，也不生成导出文件；它只冻结并验证这些生产者接入系统分享前必须满足的路径、MIME 与生命周期边界。
- 系统 chooser 的“用户未选择目标”不能由 `startAbility` 精确回调识别；已知取消视为正常结果，不能向用户展示平台原始错误。
- 真机人工分享会触发外部应用，应由用户在指定测试目标上执行，测试记录不得包含 Cookie、正文或内部文件路径。
