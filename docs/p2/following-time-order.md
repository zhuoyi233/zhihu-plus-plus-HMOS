# 关注页时间排序（#81）

关联：<https://github.com/zhuoyi233/zhihu-plus-plus-HMOS/issues/81>。

## 行为

- 顶部保留原来的“推荐 / 动态”两个频道，支持点击或左右滑动切换，两个页面分别持有仓储、列表和分页游标。
- “推荐”使用既有 `moments_v3?feed_type=recommend` 接口，保留服务端排序和最近更新用户行。
- “动态”使用既有 `/api/v3/moments?limit=10&desktop=true` 接口；列表顶部另提供“默认 / 按时间”排序选项，默认保留接口顺序。
- 时间指关注动态的发生时间，包含发布、赞同等行为，不是原文发布时间。开启“按时间”后，首屏、刷新和分页合并后均按动态时间倒序排列。
- 优先使用动态的 `created_time`，缺失或无效时使用 `updated_time`；均无有效时间的条目放在末尾。相同时间保留原顺序，内容仍按类型和 ID 去重。
- 频道选择和动态排序独立保存，启动时在页面挂载前恢复，后续经 AppStorage 广播；选择动态排序不会跳转频道或影响推荐页排名。
- 切换排序只改变当前列表的展示顺序，不重发请求，不重置分页游标或中断在途请求；切回“默认”恢复原始接口顺序。
